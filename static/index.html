Architectural Innovations Implemented Decoder-Only

1. Grouped-Query Attention (GQA): Replaces MHA by sharing KV projections across 4 queries, reducing memory bandwidth bottleneck during autoregressive decoding.

2. Rotary Position Embeddings (RoPE): Applies rotation matrices in the complex plane to query/key pairs for relative position encoding with long-context extrapolation.

3. SwiGLU Gated Feed-Forward: Uses Swish-gated activations with 8/3 expansion factor over standard ReLU/GELU.

4. Mixture of Experts (MoE): Sparse routing layer routing each token to top-2 out of 4 experts with dynamic auxiliary load-balancing loss.
